部署後的主機服務可能處理 IP 位址、請求時間及瀏覽器等連線資訊；正式主機、處理地區及保存方式待確認。若採用 GitHub Pages，亦須參閱GitHub 隱私聲明。

點選 LINE 或 Email 連結後，相關資訊由所使用的通訊服務處理。

軟體中的本機資料

依已查閱的主要程式，使用者選取的音檔、檔名、按鍵名稱、音量效果、背景圖片與設定會保存在本機 IndexedDB。舊版資料移轉後，原 localStorage 資料仍可能保留。

匯出的 JSON 備份包含音檔與設定。刪除程式內資料不會自動刪除另外匯出的備份；尚未提供完整清除流程，須另行確認。

程式啟動時建立全域鍵盤監聽，暫存按鍵按下狀態，用於背景控制與避免連發。關閉背景發聲會停止背景觸發，但監聽器仍運作，直到程式結束。在已查閱的主要程式中，未見把鍵盤事件保存為輸入紀錄或主動上傳的功能。

上述為主要程式檢視結果，不代表已完成所有相依套件、連線行為或發行安裝檔的完整稽核。
